# Security Policy

## Supported version

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, exposed credential,
or data-leak concern. Use the repository's private GitHub security advisory
form. If private vulnerability reporting is not yet enabled, contact the
repository owner privately through GitHub.

Include the affected version, reproduction steps, impact, and any proposed
mitigation. Do not include real credentials, client data, licensed market data,
or other sensitive information in a report.
